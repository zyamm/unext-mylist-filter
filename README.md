# unext-mylist-filter

マイリスト画面において「女優・監督」による動画の絞り込み機能を追加する Chrome 拡張機能です。

## 主な機能・特徴
- **「女優・監督」による絞り込み**: ドロップダウンリストで選択した項目に紐づく動画カードのみを抽出・表示します。
- **仮想スクロール（動的描画）対応**: スクロールに伴って生成される動画カードをリアルタイムで監視・キャッシュし、未読み込みカードの全件自動収集スキャンを行います。
- **オリジナルのレスポンシブデザイン完全再現**: サイト本来の1行あたりの表示カード数（3〜7個）やグリッドスタイルを自動的に読み取り、画面サイズ変更時も元のレイアウトと完全に同期します。
- **左上詰めのレイアウト整理**: 絞り込み時は空きスペースを作らず、左上から順番にカードを詰めて表示します。「指定なし」を選択すると元のマイリスト表示へ即座に復元されます。

## 使用方法
1. データ抽出ツール（`mylist-data-extractor` 等）を実行し、`local_data.json` を生成します。
2. 生成された `local_data.json` を本リポジトリのルートフォルダ直下に配置します。
3. Chromeの拡張機能管理画面（`chrome://extensions`）を開き、右上の「デベロッパーモード」を有効にします。
4. 「パッケージ化されていない拡張機能を読み込む」から本フォルダを選択して読み込みます。
5. マイリスト画面を開くと、「追加順」ボタンの横に「絞り込み」ドロップダウンが追加されます。

## ファイル構成
* `manifest.json`: 拡張機能の設定ファイル
* `content.js`: UIの挿入、DOM監視、レスポンシブスタイル同期、カードの抽出・描画を行うスクリプト
* `local_data.json`: 各動画（PID）とタグID・名前の紐付けデータ（※`.gitignore` によりGit管理対象外推奨）

## 各ファイルの仕様

**manifest.json**
- Manifest V3規格に準拠した設定ファイル。
- `content_scripts`: 対象URL（`*://app.hnext.jp/library/mylist/*`）にマッチした際、`content.js` を自動で挿入・実行します。
- `web_accessible_resources`: 拡張機能内のコンテンツスクリプトから `local_data.json` を非同期リクエスト（`fetch`）で読み込めるようアクセス権限を許可します。

**content.js**
- **データ読み込み**: `chrome.runtime.getURL` 経由で `local_data.json` を取得し、メモリ上に保持します。
- **UI動的注入**: 既存の「追加順」ボタンの隣に、サイトの見た目（Tailwind CSSクラス）に合わせた「絞り込み」ドロップダウンUIを注入します。
- **カードの全件キャッシュ**: 仮想スクロールで消去・描画される動画カード（`<article>`）を `MutationObserver` でリアルタイムに検知し、複製してキャッシュ（Map構造）に保存します。未描画カードがある場合は自動スクロールで事前収集します。
- **レスポンシブスタイルの動的同期**: サイト本来の `.grid` 要素の計算済みスタイル（`grid-template-columns` など）を `getComputedStyle` や `ResizeObserver` で取得し、カスタムグリッドへリアルタイムに同期させることでオリジナルのレイアウトを完全再現します。
- **絞り込み表示制御**: 選択された `aliasId`（女優・監督）に一致する動画カードのみ抽出し、専用のグリッド（`#custom-filter-grid`）へ左上詰めで並べます。「指定なし」時は元の仮想スクロール構造へ安全に復元します。

**local_data.json**
- **extractedAt**: データの抽出日時を示すタイムスタンプ。
- **packages**: 各動画パッケージのコンテンツID（PID）をキーとし、それに紐づく人物（`aliases`）、シリーズ・メーカー（`brands`）、検索タグ（`tags`）のIDリストを保持します。
- **dictionaries**: 各IDから実際の表示名称（女優名・監督名など）へ相互変換するための辞書オブジェクト。`aliases` 辞書のデータを基に「絞り込み」ドロップダウンの選択肢が生成されます。
